# Tech Store

A modern React e-commerce frontend built without a database.

## Features

- Product listing from data.js
- Search products
- Brand filter
- Price sorting
- Wishlist
- Shopping cart
- Quantity management
- Product details modal
- Toast notifications
- Local Storage persistence
- Responsive premium UI

## Tech Stack

- React.js
- JavaScript (ES6)
- CSS3
- Vite

## Run Project

```bash
npm install
npm run dev
```
